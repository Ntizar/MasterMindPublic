Arquitectura

Un orquestador, muchos especialistas

Nada de cadenas de agentes genéricos: cada skill se especializa en un dominio y MasterMind decide quién ejecuta. GitHub es la fuente de verdad.

Lo que aporta el sistema

  • Búsqueda semántica de skills — ChromaDB + embeddings. Pides «analiza este PDF denso» y encuentra el skill, sin memorizar nombres.
  • Human loop en cambios críticos — planificar, esperar aprobación, implementar, sintetizar. Diffs visibles y rollback siempre disponible.
  • Aprendizaje continuo — cada sesión alimenta memoria, notas y skills nuevos: el sistema mejora con el uso.

Flujo

De la pregunta al resultado, con control

  1. Consulta — ChromaDB recupera los skills relevantes por significado.
  2. Clasificación — nivel de ejecución 1-4 según complejidad y coste.
  3. Delegación — subagentes especializados ejecutan en paralelo cuando aporta.
  4. Verificación — el resultado se comprueba contra la realidad antes de reportar.
  5. Aprendizaje — skill, nota o memoria nueva si la sesión enseñó algo.

Human loop en cada fase.

Los cambios críticos (más de 5 archivos, arquitectura, despliegue) se planifican, se presentan y esperan aprobación explícita antes de ejecutarse. Y «Listo» sin prueba verificable no cuenta como listo: cada entrega llega con su receipt.

Evolución

De agente monolítico a ecosistema modular

Simpleza sobre complejidad: la delegación nativa reemplaza las cadenas de agentes, los skills sustituyen a los procesos genéricos, y lo que no aporta se poda.

  • Un único script canónico de sincronización, no cinco.
  • Cero modelo, ruta o identificador incrustado en el código: todo se lee de la configuración.
  • El catálogo crece por dominio; los duplicados se fusionan.
  • Cada ciclo deja el sistema más pequeño de ruido y más grande de conocimiento.

Inicio rápido

Pruébalo en 3 pasos

  1. Clona el repositorio — skills, scripts del motor y documentación.
  2. Copia los skills a tu agente — funciona con Hermes Agent; el patrón es portable a cualquier agente con skills.
  3. Indexa y trabaja — índice semántico en ChromaDB y tu primera tarea: el orquestador clasifica, delega y aprende.
git clone https://github.com/Ntizar/MasterMindPublic.git
cd MasterMindPublic
cp -r agent/skills/* <tu-agente>/skills/

# índice semántico de skills (ChromaDB + embeddings)
python scripts/indexar-skills.py
